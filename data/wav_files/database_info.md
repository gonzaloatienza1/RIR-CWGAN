# Database Information

This repository uses a room impulse response (RIR) database referenced in the following paper:

**Title:** A room impulse response database for multizone sound field reproduction (L)

**Publication:** The Journal of the Acoustical Society of America

**Link to the paper:** https://pubs.aip.org/asa/jasa/article/152/4/2505/2839595/A-room-impulse-response-database-for-multizone
